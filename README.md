# Enterprise Technology Projects

Personal GitHub Pages landing page for independent demonstration applications.

## Publish

1. Create the public GitHub repository `sachintechpro.github.io`.
2. Upload `index.html` to the repository ROOT (not nested in a folder).
3. Under Settings → Pages, choose Source: Deploy from a branch; Branch: main; Folder: /(root), then Save.
4. Open https://sachintechpro.github.io/ once GitHub Pages finishes deployment.

The live demo links retain their existing Render hostnames. Edit `index.html` to change project descriptions or destinations.
